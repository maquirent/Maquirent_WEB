## Dirección visual

Fotografía real de la empresa como protagonista, títulos condensados, contraste entre carbón y amarillo, superficies claras y pocos elementos decorativos. La home sigue el recorrido: propuesta de valor → categorías → servicios → empresa → proceso → contacto. El panel usa una barra lateral estable y formularios con vista previa, con el modo de demostración claramente identificado.
